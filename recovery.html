Other ways to fix this

Re-run the installer. In FieldLink Admin → Kiosk → ⚙ Settings on the display → Download setup package. Copy the ZIP to this PC, sign in as an administrator (Ctrl+Alt+Del → Switch user), extract it and double-click INSTALL.bat. It is safe to run any number of times: it updates the app, applies the new key and repairs the lockdown.

Keyboard: Ctrl+Shift+K this screen · Ctrl+Shift+R reload · Ctrl+Shift+Q quit the app

How to get a pairing code

  1. On any computer or phone, sign in to FieldLink Admin.
  2. Open Kiosk in the left menu.
  3. Next to the key for this display click 🔗 Link kiosk. If the key was deleted, create a new key first with + Generate Key.
  4. Type the 8-character code shown there into the box on the left and press Link this kiosk.

Codes work once and expire after 15 minutes. Only Super Admins can create them.

Need a keyboard?

Plug any USB keyboard into the kiosk PC. Touch screens also work for the buttons; typing needs a keyboard.

Administrator access

Press Ctrl+Alt+Del → Switch user and sign in with your own Windows account. The kiosk account has no desktop by design.
